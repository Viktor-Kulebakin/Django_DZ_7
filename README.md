# Employees Management App 👥

Веб-приложение для управления сотрудниками, полностью упакованное в Docker-контейнеры.
Проект автоматически поднимает сервер приложения (Django) и реляционную базу данных.

## 🛠 Технологический стек
* **Python 3.12-slim** (Оптимизированный базовый образ)
* **Django** (внутри контейнера `web`)
* **Gunicorn** (production-ready веб-сервер)
* **Docker & Docker Compose** (для оркестрации сервисов)

---

## 🚀 Быстрый запуск (Локально)

Интеграция с WSL 2 настроена. Для запуска проекта вам понадобятся только установленные **Docker Desktop** и **Git**.

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd ИМЯ_РЕПОЗИТОРИЯ
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корне проекта на основе шаблона (если у вас есть `.env.example`), 
либо просто убедитесь, что необходимые секреты и пароли для БД прописаны локально.

### 3. Сборка и запуск контейнеров
Запустите сборку образов и старт всех сервисов в фоновом режиме:
```bash
docker compose up --build -d
```

### 4. Проверка работы
* Приложение будет доступно в браузере по адресу: [http://localhost:8000](http://localhost:8000)
* Чтобы посмотреть статус контейнеров: `docker compose ps`
* Чтобы читать логи приложения в реальном времени: `docker compose logs -f web`

---

## 🛑 Остановка проекта
Чтобы остановить сервер и удалить контейнеры, выполните:
```bash
docker compose down
```
